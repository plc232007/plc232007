### 🧠 `forward()` — quem está do outro lado da rede

```python
class Pedro(nn.Module):
    """Estagiário de IA · Ciência da Computação no IESB (2025–2028) · Brasília, DF"""

    foco_atual = ["visão computacional", "detecção de objetos", "deep learning"]
    treinando  = {"modelos": "YOLO", "framework": "PyTorch", "imagens": "OpenCV", "dados": ["Pandas", "NumPy"]}
    base       = ["fullstack (React · Next.js · Flask · FastAPI)", "requisitos", "SQL"]

    def forward(self, problema):
        requisito = self.entender(problema)          # comecei como analista de requisitos
        modelo    = self.treinar(requisito)          # hoje: visão computacional na CNT
        return self.colocar_em_uso(modelo)           # API, banco e interface em volta do modelo
```

Hoje sou **estagiário de IA e Visão Computacional na CNT**, aplicando visão computacional à **Pesquisa CNT de Rodovias**, que avalia as condições das rodovias brasileiras. Treino e avalio modelos **YOLO em PyTorch**, comparo métricas entre experimentos, preparo dados com **Pandas e NumPy**, processo imagens com **OpenCV** e documento os resultados para a equipe.

Antes, fui **analista de requisitos** e depois **desenvolvedor fullstack** na Engesoftware. É essa combinação que eu trago: entender o problema, treinar o modelo e construir o que fica em volta dele.
